天界闘技 ヘヴンズ・アリーナ（配布版）

■ フォルダの中身
  index.html   … ゲーム本体（絵・効果音・ルールなどはすべてこの中に入っています）
  bgm/         … BGM 6曲（title / menu / battle / final / win / lose）

■ 注意
  ・index.html をダブルクリックして直接開くと、ブラウザの制限で BGM が鳴らないことがあります。
    GitHub Pages などで公開したURLから遊んでください。
  ・オンライン対戦は PeerJS（無料の通信サービス）を使っています。インターネット接続が必要です。
  ・オンライン対戦はホストのブラウザで進行します。ホストは対戦中に画面を閉じたり、
    スマホをスリープさせたりしないでください。
  ・学校・会社などのWi-Fiでは、つながらない場合があります（その場合はモバイル回線で試してください）。

■ GitHub Pages での公開手順（概要）
  1. GitHub でアカウントを作り、新しいリポジトリ（Public）を作成
  2. 「Add file」→「Upload files」で index.html と bgm フォルダをアップロード
  3. 「Settings」→「Pages」→ Branch を「main」「/ (root)」にして Save
  4. 数分後に表示される https://ユーザー名.github.io/リポジトリ名/ が遊ぶためのURL
